# Primeiros Socorros | Mapa Mental

Um mapa mental interativo desenvolvido para apresentar informações básicas de primeiros socorros de forma visual, organizada e fácil de consultar.

O projeto foi criado como uma forma de aplicar conhecimentos de HTML, CSS e JavaScript em uma aplicação com interação e manipulação do DOM.

## Sobre o projeto

O usuário pode abrir o mapa mental, visualizar diferentes temas de primeiros socorros e abrir caixas com informações sobre cada situação.

Os elementos do mapa também podem ser movimentados livremente, permitindo reorganizar a visualização.

## Funcionalidades

* Mapa mental interativo
* Botões arrastáveis
* Caixas de conteúdo arrastáveis
* Linhas que acompanham os elementos durante o movimento
* Abertura e fechamento das informações por duplo clique ou toque
* Animações de abertura e fechamento
* Layout responsivo para diferentes tamanhos de tela
* Conteúdo sobre:

  * Queimaduras
  * Engasgamento
  * Crises convulsivas
  * Hemorragias
  * Parada cardiorrespiratória
  * Luxação
  * Urgências e emergências

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* SVG

## Como utilizar

Abra o projeto no navegador.

No mapa:

* Clique duas vezes ou toque duas vezes em um tema para abrir suas informações.
* Arraste os temas para movimentá-los.
* As caixas de conteúdo também podem ser arrastadas.
* O mapa pode ser utilizado em computadores e dispositivos móveis.

## Objetivo

O objetivo do projeto foi desenvolver uma aplicação interativa que unisse organização visual, funcionalidade e conteúdo informativo, além de colocar em prática conceitos de JavaScript e manipulação de elementos da página.

## Aprendizados

Durante o desenvolvimento, trabalhei principalmente com:

* Eventos do JavaScript
* Manipulação do DOM
* Posicionamento de elementos
* `getBoundingClientRect()`
* Eventos de mouse e pointer
* Manipulação de SVG
* Criação e atualização de linhas dinamicamente
* Responsividade com CSS
* Animações com CSS e JavaScript

## Observação

O projeto possui finalidade educativa. As informações apresentadas não substituem treinamento em primeiros socorros nem orientação de profissionais de saúde.
